# Oum's Design Avengers

A skill that helps a coding agent design beautiful websites, step by step,
like a team of Avengers where each hero has one job.

## Install

```
/plugin install oum-design-skill --marketplace GuptaOum/oum-design-skill
```

Or download the zip from [Releases](https://github.com/GuptaOum/oum-design-skill/releases)
and upload it to your agent's skills.

**Use it** by asking to design or redesign a web page, or just say
**"assemble"**, **"design avengers"** or **"oum design"**.

## How they work together

Like the Avengers, they don't all fight every battle. The team leader calls
the right heroes, in the right order:

| Step | Mission | Heroes called |
|---|---|---|
| 1 | **Briefing:** understand the page and its goal | Team leader |
| 2 | **Research:** find great reference sites | Doctor Strange, Spider-Man, Scarlet Witch |
| 3 | **Direction:** choose one look and stick to it | Nick Fury, Wakanda |
| 4 | **Build:** create the page | Iron Man, Jarvis, Vision |
| 5 | **Motion and 3D:** bring it to life | Thor, Captain Marvel, the Guardians |
| 6 | **Polish:** perfect every detail | Black Widow |
| 7 | **Review:** critique and fix | Captain America, Professor X |
| 8 | **Verify:** test until it holds up | Hawkeye, Hulk |

### Smaller missions

| You ask for… | Heroes called |
|---|---|
| A full website | The whole team |
| "Polish my page" | Doctor Strange, Black Widow, Captain America, Hawkeye |
| "It looks generic" | Nick Fury, Captain America, Hawkeye |
| "Animations feel off" | Thor, Black Widow, Hawkeye |
| 3D or particles | Captain Marvel, Thor, Hawkeye |
| "Make it look like Apple" | Wakanda, Black Widow, Captain America |
| Art, 3D or textures | The Guardians: Rocket, Groot, Star-Lord, Drax |
