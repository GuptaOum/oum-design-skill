# Oum's Design Avengers

An agent skill that turns "design me a website" into a disciplined, end-to-end
workflow: research → direction → build → motion → polish → review → verify.

It assembles a team of design tools, each named after an Avenger, and calls
only the ones a request needs.

## What's inside

- **The team:** 20 members, covering:
  - research with Awwwards and Scrapling
  - one committed design direction
  - clean component builds
  - motion
  - Apple-style design and Liquid Glass
  - 3D and WebGL with React Three Fiber and GLSL
  - free asset sources (Spline, Unicorn Studio, LottieFiles, Rive, Poly Haven, ambientCG)
  - review, browser verification and stress testing
- **Thor's armoury:** which motion tool to use, and when:
  - Framer Motion for React UI and scroll scenes
  - GSAP with ScrollTrigger for cinematic timelines
  - React Three Fiber with shaders for particles and 3D
  - plain CSS for simple hovers and reveals
- **Jarvis protocol:** check current library docs through Context7 before writing library code.
- **Captain Marvel's lab:** a WebGL, GLSL and React Three Fiber guide, with performance and fallback rules.
- **Wakanda:** Apple design and Liquid Glass, from cheap CSS frosted glass to true refraction.
- **The Guardians' asset bay:** free, plug-and-play 3D, animated art and textures, with licence notes.
- **S.H.I.E.L.D. archive:** an index of every design skill by job.
- **Scaling the mission:** which stages to run for a full site, a polish pass, a single hero, 3D, an Apple look or asset hunting.

## Install

Create a folder named `oum-desing-skill` in your coding agent's skills
directory, then put `SKILL.md` inside it. It triggers when you ask to design,
build, redesign or restyle a web page, or say "assemble", "design avengers"
or "oum design".

Tools the skill names, such as Awwwards, AnimatedWebs, Spline, Context7 and
Figma, are optional. If one isn't connected, the workflow says so and carries
on with the rest.
